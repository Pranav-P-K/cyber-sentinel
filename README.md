# CyberSentinel: Intelligent SOC Copilot for Threat Analysis

**CyberSentinel** is an explainable LLM-powered triage system that transforms raw Intrusion Detection System (IDS) alert streams into grounded, MITRE-mapped attack narratives, complete with a built-in hallucination verifier. 

It addresses the critical challenges in modern Security Operations Centers (SOCs), specifically alert fatigue, isolated analysis, LLM hallucinations, and lack of explainability, through a unified 6-layer pipeline.
